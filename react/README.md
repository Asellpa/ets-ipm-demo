# ETS IPM frontend

React and TypeScript frontend. Current installation, verification and production instructions are in the [root README](../README.md).

From this directory, `npm run demo` starts the development frontend on 5175. Start the API separately from the repository root with `npm run dev`. These commands are for local development, not production.

End-user instructions are under **Help & guides** and [the user guide](../docs/guides/USER_GUIDE.md). Do not run demo reset/setup commands as an upgrade.
